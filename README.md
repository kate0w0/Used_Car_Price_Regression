# Предсказание цены подержанного автомобиля

## Данные

**Used Car Price Prediction Dataset** - 4009 объявлений, 12 исходных колонок.
Источник: <https://www.kaggle.com/datasets/taeefnajib/used-car-price-prediction-dataset>

## Гипотезы (сформулированы до экспериментов)

| № | Гипотеза |
|---|---|
| H1 | Обучение на `log(price)` вместо `price` даст лучший RMSE (в долларах) |
| H2 | Линейная модель сработает не хуже ансамблевых методов, потому что по графикам часть признаков влияет на цену линейно |
| H3 | Ridge (L2) обойдёт Lasso (L1) на тесте из-за мультиколлинеарности признаков двигателя |
| H4 | Признаки цвета не влияют на цену: их удаление не ухудшит RMSE |
| H5 | Самые важные признаки - мощность (`hp`) и пробег (`milage`) |
| H6 | Удаление наблюдений с ценой выше 1 млн сделает модели стабильнее |

## Результаты по гипотезам

| № | Итог | Почему |
|---|---|---|
| H1 | подтвердилась для линейной модели, частично для ансамбля | Ridge: RMSE 61.3k → 55.9k (p = 0.0008), MAE 22.5k → 13.6k. У леса значимо только MAE (13.5k → 11.6k, p = 0.009), по RMSE p = 0.080: логарифм не меняет сами разбиения, только усреднение в листьях |
| H2 | **не подтвердилась** | Ridge проигрывает лесу 2470\$ RMSE / 2310\$ MAE и бустингу 3775\$ / 2628\$ (p = 0.008, 0.013 и p < 0.0001). Предпосылка при этом верна - Ridge уверенно обходит одиночное дерево. Ансамбли выигрывают за счёт взаимодействий, которые аддитивная модель не ловит |
| H3 | **не подтвердилась** | Ridge = Lasso = OLS: 55853 у всех трёх. Оптимальная α упирается в нижнюю границу сетки, кривые train и CV плоские - переобучения нет, подавлять нечего. Lasso оставил 50 ненулевых коэффициентов из 53. Расширение до poly2 картину не изменило (p = 0.90) |
| H4 | подтвердилась | У Ridge ни один вариант удаления не значим (p от 0.057 до 0.68). У леса удаление обоих цветовых признаков метрику даже значимо улучшает (+126\$, p = 0.018): это разреженные столбцы, по которым дерево иногда делит выборку на шуме |
| H5 | подтвердилась частично | У леса - буквально: `milage` +7.8k к MAE, `hp` +6.6k. У Ridge `hp` только четвёртый, впереди пробег, возраст и марка. При групповой перестановке блок `hp + liter + cylinder` выходит на первое место у обеих моделей (+8.9k и +5.8k), поэтому корректная формулировка - «двигатель и пробег» |
| H6 | **не подтвердилась** | Удаление двух машин дороже 1 млн из трейна не меняет ничего, а более агрессивная чистка (верхний 1% цен) ухудшает обе модели: Ridge R² 0.670 → 0.611, лес 0.807 → 0.693. Один Porsche Carrera GT в тесте даёт 71.7% суммарного квадрата ошибки, но MedAE при его удалении меняется с 5109 на 5108 - проблема в метрике, а не в моделях |

## Что сделано

- **EDA:** распределение цены (логнормальное) и её логарифма, боксплоты по категориальным признакам, скаттеры по числовым, корреляционная матрица, разбор структуры пропусков.
- **Признаки из текста:** `hp`, `liter`, `cylinder`, `engine_type` из `engine`; `speed`, `is_automatic` из `transmission`; базовые цвета из `ext_col` / `int_col`; флаги `is_base` / `is_sport` / `is_premium` из `model`; `age`.
- **Подготовка:** всё внутри `Pipeline` + `ColumnTransformer`, поэтому утечки между фолдами нет. Пропуски `fuel_type` восстанавливаются по типу двигателя отдельным шагом; числовые - `KNNImputer(k=5, add_indicator=True)` (значимо лучше медианы: p = 0.003). Кодирование - `TargetEncoder` для `brand` и `OneHotEncoder` для остальных, выбор подтверждён экспериментом. Таргет - `log(price)` через `TransformedTargetRegressor`.
- **Модели:** константа, OLS, Ridge, Lasso, решающее дерево, случайный лес, `HistGradientBoosting`.
- **Метрики:** RMSE, MAE, MedAE, MAPE, R². Решения принимаются по MAE и MedAE, так как RMSE на этих данных определяется единичными объектами.
- **Валидация:** `RepeatedKFold` (5×2) и парный t-тест по одним и тем же фолдам - без него разница между моделями неотличима от разброса.
- **Гиперпараметры:** `GridSearchCV` для Ridge, Lasso, леса и бустинга, с разбором кривых.
- **Отбор признаков:** `SelectKBest(f_regression)` по числу признаков + permutation importance (одиночная и групповая, по исходным колонкам).

## Итоговое качество на отложенном тесте

| Модель | RMSE | MAE | MedAE | MAPE | R² |
|---|---|---|---|---|---|
| Константа (медиана), CV | 76153 | 27578 | - | - | −0.05 |
| Ridge* | 27252 | 11466 | 5108 | 27.2% | 0.670 |
| RandomForest* | 20983 | 8844 | 4318 | 22.9% | 0.805 |
| HistGB* | 22432 | 9163 | 4440 | 22.6% | 0.777 |

Тест без единственной машины дороже 1 млн (Porsche Carrera GT): на полном тесте она одна поднимает RMSE Ridge с 27.3k до 51.2k и роняет R² с 0.670 до 0.386. Полная таблица с обоими вариантами - в ноутбуке.

**Вывод.** Основной прирост дали не модели, а работа с данными: признаки из текстового описания двигателя, KNN-заполнение пропусков, логарифм таргета и таргет-энкодинг марки. Переход от линейной модели к ансамблю добавил ещё около 8% MAE и стоил интерпретируемости. Модель систематически занижает цену дорогих машин - комплектация из `model` не используется, и это первое, что стоит доделать.
